# Lvguangcheng

### I like turning ideas into things people can actually use.

I am a developer who enjoys building a complete piece of work from scratch: a clean interface, clear logic, and details polished until the whole thing feels right in the hand. More than chasing new frameworks, I care whether something is pleasant for a real person to use.

This site is hand-written in vanilla HTML, CSS and JavaScript — no framework, no build step, it runs in the browser as-is. All the content lives in Markdown files, so publishing is as easy as editing notes and refreshing.

- **Think more, write less** — break the problem down first, avoid code for code's sake
- **Start with the dumbest version** — make it run, then optimise; get real feedback early
- **Finishing matters more than starting** — empty states, error messages and mobile layouts are where the experience is won

## What I am working on

- **Polishing this site** — filling in content, sharpening the information hierarchy, improving mobile reading
- **A small web tool** — the goal is to open it and use it: no sign-up, no network required
- **Writing things down** — turning the pitfalls I hit into short posts, for myself and for whoever passes by
