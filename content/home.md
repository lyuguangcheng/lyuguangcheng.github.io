# 吕广成

### 把想法做成能用的东西。

我是一名开发者，喜欢从零搭起一个完整的作品：把界面做干净、把逻辑理清楚、把细节磨到手感对。比起追逐新框架，我更在意一个东西能不能被真实的人顺手用起来。

这个网站是我用原生 HTML、CSS 和 JavaScript 手写的——没有框架、没有构建步骤，双击就能在浏览器里跑。所有内容放在 Markdown 文件里，改完刷新即可，像写笔记一样发布。

- **写得少，想得多** — 动手前先把问题拆开，避免为了写代码而写代码
- **先从最笨的版本开始** — 能跑通再谈优化，早一点拿到真实反馈
- **收尾比开头重要** — 空状态、错误提示、移动端这些没人夸的地方，才是体验的分水岭

## 目前在做的事

- **打磨这个站点** — 补齐内容、理顺信息层级、继续优化移动端阅读体验
- **做一个网页小工具** — 目标是打开就能用：不用注册，不依赖网络
- **持续记录** — 把踩过的坑写成随笔，方便自己也方便路过的人
